# Multi30k dataset

**Cluster:** [[Phase 0 - Vanilla Transformer]]

## Intuition
~30k German–English image-caption sentence pairs; a small DE→EN translation benchmark, the right size for a first from-scratch encoder-decoder before scaling up.

## Connects to
[[Phase 0 - Vanilla Transformer]] · [[BLEU and perplexity]] (BLEU is the translation metric)

## Reference
Elliott et al., "Multi30K: Multilingual English-German Image Descriptions," 2016 — [arXiv:1605.00459](https://arxiv.org/abs/1605.00459).
